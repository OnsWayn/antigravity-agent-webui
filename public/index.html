🚀 `antigravity-preview-05-2026` 核心功能与使用指南

Antigravity Agent 是基于 Gemini API 的全功能托管式 AI Agent。通过单个 API 调用，即可自动获得具备推理、代码执行、文件管理以及网页检索能力的全功能 Agent。

一、 已支持的核心功能 (Supported Capabilities)

  • 代码执行 (Code Execution)：在云端独立 Linux 沙盒中运行 Bash、Python、Node.js 脚本，支持安装第三方 pip/npm 依赖包。
  • 文件系统持久化 (Filesystem)：支持在 `/workspace` 目录下创建、修改、检索文件。文件在同一个 `environment_id` 内保持持久化状态。
  • 网络访问 (Web Access)：支持通过 Google Search 实时检索公开信息，并使用 URL Context 抓取网页内容。
  • 多模态输入 (Multimodal Input)：支持传入文本与 Base64 格式图片进行视觉与代码联合分析。
  • 自定义函数 (Function Calling)：支持定义客户端 Function，在二轮交互中传递 `function_result`。
  • 远程 MCP 服务 (Remote MCP)：支持注册基于 HTTP 协议的外部 Model Context Protocol 服务器。
  • Token 预算管理 (Budget Control)：支持设置 `max_total_tokens`，达到限制时返回 `status: incomplete`，可通过 `previous_interaction_id` 无缝恢复。
  • 同一沙盒多会话：可以共享同一个 `environment_id` 中的文件，同时创建多个互不继承对话上下文的独立会话。
  • 本地会话持久化：使用 SQLite 保存会话、交互轮次、Token 用量、执行状态、错误与产物元数据；API Key 不会写入数据库。
  • 官方快照文件提取：支持完整路径或只输入文件名自动定位，目标文件以二进制响应下载，避免 Base64 额外体积。

二、 沙盒与会话的区别

  • 沙盒环境由 `environment_id` 标识，保存 `/workspace` 等目录中的文件。
  • 对话上下文通过 `previous_interaction_id` 延续，与沙盒文件系统不是同一概念。
  • 点击“当前沙盒新会话”会保留沙盒及其文件，但不发送旧的 `previous_interaction_id`；原会话历史仍可单独切换和继续。
  • “新沙盒”会同时创建新的远程环境和新的会话，不复用原环境文件。

三、 ⚠️ 预览版功能限制与注意事项 (Limitations & Caveats)

限制分类 限制说明与细节
生成参数不兼容 不支持 `temperature`、`top_p`、`top_k`、`stop_sequences`、`max_output_tokens`。传入会返回 400 错误。
结构化输出 当前 Antigravity Agent 不支持原生的 JSON Schema 结构化输出 (Structured Output)。
暂未支持的工具 `file_search`、`computer_use` (电脑屏幕操作)、`google_maps` 暂未在 Agent 中开放。
MCP 服务器限制 暂不支持 SSE (Server-Sent Events) 传输模式（仅支持 HTTP 模式）；MCP 服务器 `name` 必须严格为纯小写字母与数字。
环境文件下载 Gemini Files API 返回的是完整 TAR 快照，因此首次提取速度取决于整个环境大小，而不只是目标文件大小。本 WebUI 会缓存快照 60 秒，连续提取多个文件时可复用缓存；Agent 成功修改环境后缓存会自动失效，也可勾选“强制刷新环境快照”。
文件提取安全限制 单个目标文件默认最大 50 MB，单次快照最多处理 512 MB；路径不能包含 `..` 或空字节。同名文件不唯一时必须选择完整路径。
环境有效期 远程环境由 Google 托管并可能在长时间不活跃后被清理。SQLite 只保存本地会话历史和元数据，不会复制或永久保留整个远程文件系统。
多模态类型限制 目前仅支持文本和图片 (Image) 输入，音频 (Audio)、视频 (Video) 和 PDF 直接上传暂未开放。
